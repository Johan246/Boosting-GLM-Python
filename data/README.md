# Data

Source datasets are not committed to this repository. Download them from the original public R repository:

```bash
boosting-glm download-data --output data/raw
```

Supported files:

- `freMTPL2freq.csv`
- `ausprivauto0405.rda`
- `mtpl_be.rda`
- `norauto.rda`

The unpublished corporate `REAL` dataset used by an optional branch of the R code is not supported.
